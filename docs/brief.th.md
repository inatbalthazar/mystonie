## 1. สรุปในหนึ่งย่อหน้า

**Mystonie** (my + stone มาจาก *Milestone* มีมาสคอตเป็นก้อนหินชื่อ Stonie) คือ **"Strava for the shows and movies you finish"** ทุกครั้งที่ดูหนังจบ ดูซีรีส์จบ หรือดูจบทีละตอน Mystonie จะสร้าง **artwork สวย ๆ พร้อมสถิติ** ให้แชร์ลง Instagram Stories, X หรือ TikTok ได้ทันที เมื่อเวลาผ่านไป artwork เหล่านี้กลายเป็นสมุดสะสมส่วนตัว แอปยังบอกได้ด้วยว่าเรื่องไหนมีฉากที่คุณไม่อยากเจอ

**Tagline:** *"Finished it? Mystonie it."*

## 2. หลักการของแผน

1. **วงจรหลักวงจรเดียว:** ดูจบ → ได้การ์ด → แชร์
2. **มีประโยชน์กับผู้ใช้คนเดียวก่อน ค่อยเพิ่มส่วนสังคม:** ฟีเจอร์ต้องมีค่าแม้ไม่มีเพื่อนในแอป ฟีเจอร์ที่ต้องมีคนเยอะก่อนรอตามเงื่อนไข (หัวข้อ 10)
3. **Global ตั้งแต่วันแรก:**
   - UI, ข้อความ, แบรนด์ และโซเชียลเป็นภาษาอังกฤษทั้งหมด
   - ภาษาไทยเป็นแค่หนึ่งในตัวเลือกภาษา
   - ไม่มีฟีเจอร์เฉพาะไทยในแกนหลัก
   - วันที่ เวลา และตัวเลขแสดงตาม locale ของผู้ใช้
4. **ใช้ของที่มีอยู่แล้วก่อนสร้างเอง:** TMDB สำหรับข้อมูลเรื่อง, DoesTheDogDie สำหรับคำเตือน, Supabase สำหรับหลังบ้าน
5. **บริการน้อยที่สุด และต้นทุนใกล้ศูนย์** จนกว่าจะมีรายได้
6. **แต่ละขั้นมีเกณฑ์ผ่าน:** ถ้าไม่ผ่าน ให้แก้สิ่งที่มีก่อน ไม่เพิ่มฟีเจอร์ใหม่

## 5. กลุ่มผู้ใช้และจุดยืน

**กลุ่มแรก:** แฟนซีรีส์และหนังทั่วโลก อายุ 16–30 ปี ที่ **ลง IG Stories, X หรือ TikTok เป็นนิสัย**
- ชุมชนที่ใช้เปิดตัว: **K-drama**, **anime** และ **ซีรีส์ตะวันตกที่กำลังเป็นกระแส** เพราะเป็นแฟนด้อมระดับโลกที่ชอบแชร์และยังไม่มีเครื่องมือทำ artwork ที่ดี

| คู่แข่ง | จุดแข็ง | จุดที่ Mystonie ชนะ |
|---|---|---|
| Letterboxd | ชุมชนหนังแข็งแรง | ไม่ทำซีรีส์ ส่วน Mystonie เน้นซีรีส์ + artwork สวยกว่า + recap อัตโนมัติ |
| Serializd | "Letterboxd for TV" | artwork, recap และคำเตือนฉาก |
| TV Time | บันทึกทีละตอน | UI รกและมีโฆษณาเยอะ ส่วน Mystonie สะอาดและสวย |
| MyAnimeList / AniList | ฐานข้อมูลอนิเมะ | ไม่เน้นการแชร์ ส่วน Mystonie รวมทุกเรื่องที่ดูไว้ที่เดียว |
| DoesTheDogDie | ข้อมูลคำเตือน | Mystonie ไม่ได้แข่ง แต่ **ใช้ข้อมูลของเขาแสดงคู่กับการบันทึก** |

**จุดยืน:** Mystonie เป็น **แอปสร้าง artwork ที่มีฐานข้อมูลอยู่เบื้องหลัง** ไม่ใช่ฐานข้อมูลที่มี UI

## 7. หลักการ UX

1. **บันทึกได้ใน 3 แตะ:** ➕ → ค้นหาขณะพิมพ์ → "Finished" ส่วนซีรีส์ที่กำลังดูมีปุ่ม **"Next episode"** บนหน้าแรกให้กดได้ใน 1 แตะ
2. **ฉลองก่อน ถามทีหลัง:** กดจบแล้วขึ้นหน้าฉลองและการ์ดทันที คะแนนและรีวิวหนึ่งบรรทัดข้ามได้
3. **หนึ่งหน้าจอ หนึ่งการกระทำหลัก:** แถบเมนูล่างมีแค่ **Home · Collection · ➕ · Me**
4. **ได้การ์ดใบแรกภายใน 60 วินาที** หลังสมัคร
5. **ตอบสนองทันที:** optimistic UI, skeleton ตอนโหลด, แอนิเมชันปั๊มตรา และ haptic บนมือถือที่รองรับ
6. **ข้อความภาษาอังกฤษแบบเป็นกันเอง:** "Finished! 🎉" แทน "Saved successfully" มีภาษาไทยให้เลือกในเมนูภาษา
7. **เวลาจบแก้ไขได้เสมอ** ค่าเริ่มต้นคือเวลาที่กดบันทึก และแสดงตามโซนเวลาของผู้ใช้

## 8. UI และ Artwork

**แนวภาพ:**
- ตัวเลขใหญ่ชัดแบบ Strava ผสมความสนุกแบบสมุดสะสม (ตราปั๊ม ตั๋ว โพลารอยด์)
- ดึงสีหลักจากโปสเตอร์ การ์ดทุกใบจึงไม่ซ้ำกัน
- Dark mode สำคัญเท่าโหมดสว่าง
- ดูเป็นแบรนด์สากล ไม่มีกลิ่นอายท้องถิ่นใด ๆ

**3 เทมเพลตแรก (ขั้น 0):**
1. **Ticket:** ตั๋วหนังพร้อมรอยปรุ เหมาะกับหนัง
2. **Polaroid:** โปสเตอร์ในกรอบโพลารอยด์ + ลายมือ เหมาะกับทุกประเภท
3. **Bold Stats:** มินิมอล ตัวเลขใหญ่แบบ Strava เหมาะกับซีรีส์และ recap

ขนาด **9:16** (Stories/TikTok) และ **4:5** (Feed)

**การ์ดในแต่ละขั้น**

| ขั้น | การ์ด |
|---|---|
| 0 | Finish Card (3 เทมเพลต) |
| 1 | + Progress Card (ทีละตอน), **Weekly Recap**, **Stats Sticker** (PNG พื้นโปร่งใสแปะบนรูปตัวเอง) |
| 2 | + Milestone, Monthly Recap, **Year in Review (Wrapped)**, เทมเพลตพรีเมียม (Pro), **Survived Card** จากข้อมูลคำเตือน ("Survived 14 jump scares") |
| 3+ | Trending Card รุ่นพิเศษ, ตราปั๊มมีหมายเลข "Finisher #1,204", Challenge Card |

**องค์ประกอบของการ์ด:** โปสเตอร์ · ตราปั๊ม "FINISHED" + วันที่ · ตัวเลขใหญ่ · รีวิวหนึ่งบรรทัด · `mystonie · @username` + ลิงก์สั้นกลับหน้าเรื่อง

**การแชร์:** บนเว็บใช้ Web Share API พร้อมไฟล์ภาพ หรือเลือกดาวน์โหลด ส่วนการแชร์ตรงเข้า Instagram Stories ต้องใช้แอปมือถือ (ขั้น 3+)

## 9. แผนสร้างแบบเป็นขั้น

### ขั้น 0: Mystonie Card (3–4 สัปดาห์)
**ใช้พิสูจน์ว่าคนอยากทำและแชร์การ์ดนี้จริงไหม**
- เว็บหน้าเดียว **ไม่ต้องสมัคร:**
  - ค้นหาหนังหรือซีรีส์ (TMDB)
  - เลือกเทมเพลต 1 ใน 3 แบบ
  - ใส่คะแนนและรีวิวหนึ่งบรรทัด (ไม่บังคับ)
  - ดาวน์โหลดหรือแชร์
- มีฟอร์มรับอีเมล "Save all your cards in one collection. Join the waitlist"
- UI ภาษาอังกฤษ มีภาษาไทยให้เลือก มี Privacy Policy และ Terms
- **เกณฑ์ผ่าน (1 เดือนหลังเปิด):** การ์ด ≥ 500 ใบ · แชร์หรือดาวน์โหลด ≥ 30% · ลงชื่อรอ ≥ 100 คน

### ขั้น 1: Collection MVP (6–8 สัปดาห์)
**ใช้พิสูจน์ว่าคนกลับมาใช้ซ้ำไหม**
- สมัครด้วย Google และอีเมล พร้อม username
- **คอลเลกชันหนังและซีรีส์:**
  - สถานะ Want to watch · Watching · Finished
  - ซีรีส์บันทึกทีละตอนได้
  - มุมมองแบบ tiles และ list
  - สรุปเวลาดูรวมและจำนวนเรื่อง
  - เวลาจบแก้ไขได้
- การ์ดสร้างอัตโนมัติ + Progress Card + Stats Sticker + **Weekly Recap** (อีเมลหรือ web push)
- หน้าสถิติ (ตัวเลขใหญ่, heatmap, genre ประจำตัว) และโปรไฟล์ public เป็นแกลเลอรีการ์ด ปิดเป็น private ได้
- ติดตั้งเป็น PWA ได้ หมวด Trending ใช้ข้อมูลจาก TMDB
- **เกณฑ์ผ่าน:** สมัคร ≥ 1,000 คน · กลับมาใช้ในวันที่ 30 ≥ 15% · ≥ 25% ของการกดจบลงเอยด้วยการแชร์

### ขั้น 2: คำเตือนฉาก + ขยายสื่อ + รายได้ (2–3 เดือน)
1. **คำเตือนฉากจาก DoesTheDogDie API:**

## 11. Tech Stack (ตัดสินใจแล้ว)

| ส่วน | ใช้ตอนนี้ | ขยายภายหลัง |

| Logic ฝั่งเซิร์ฟเวอร์ | Next.js Route Handlers / Server Actions | Supabase Edge Functions หรือ Trigger.dev |
| ข้อมูลเรื่อง | TMDB (ขั้น 0–1) → Google Books + AniList (ขั้น 2) | RAWG + HLTB (เกม) |

## ภาคผนวก B: ระบบคำเตือนแบบชุมชนและควิซ (กฎจาก v1 สำหรับอนาคต)

- **Tag** เพิ่มหรือลบได้เสมอ: jump scares, violence, animal death (สุนัขและแมวแยกกัน), sexual content, self-harm, phobias (spiders, needles, claustrophobia), **flashing lights**
- **คำเตือนหนึ่งรายการ:** tag + ระดับความแรง + ตำแหน่ง (ซีซัน/ตอน + นาที) แสดงแบบไม่สปอยล์
- **ยืนยัน:** ≥ 5 คน และคนยืนยันมากกว่าคนแย้ง
- **ควิซ:**
  - ถามเฉพาะเรื่องที่ผู้ใช้จบแล้ว ตัวเลือกคือ Yes / No / Don't remember
  - ใช้คำถามเดิมจนมีคนตอบครบ 10 คน ฝั่งที่เห็นตรงกัน ≥ 5 คนและมากกว่าอีกฝั่งได้รางวัล
  - ทำได้ไม่จำกัด แต่ได้รางวัลแค่ 5 ควิซแรกต่อวัน (UTC)
  - ถ้าตอบเร็วเกินเกณฑ์ ไม่ได้คะแนน และถ้าทำซ้ำจะถูกระงับชั่วคราว
  - ทุกการคำนวณทำที่เซิร์ฟเวอร์
- **ต่อยอด:** ตัวกรองแบบ "ไม่มี" ("horror without jump scares") และโหมด Scene Alert เตือนระหว่างดู

## ภาคผนวก C: เศรษฐกิจในแอปและไอเดียอื่น (สำหรับอนาคต)

- **Gem:**
  - บันทึกธุรกรรมทุกรายการ (ledger)
  - ผลวงล้อ รางวัล และยอดเงินคำนวณที่เซิร์ฟเวอร์เท่านั้น
  - ขีดจำกัดรายวันใช้เวลา UTC
  - ในแอปมือถือต้องขายผ่าน in-app purchase
  - ห้ามขายสิทธิ์หมุนวงล้อด้วยเงินจริงก่อนปรึกษากฎหมาย
- **Merch:** print-on-demand ตรวจที่อยู่ก่อนจ่ายเงิน ถ้า Gem ไม่พอจ่ายส่วนต่างด้วยเงินได้
- **อื่น ๆ:** โฆษณาเนทีฟตามความสนใจ, affiliate links, การท่องเที่ยว (ประเทศที่เคยไป), AI assistant / ค้นหาด้วยภาษาพูด และ API ข้อมูลสำหรับธุรกิจ
